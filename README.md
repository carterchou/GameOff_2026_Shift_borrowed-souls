# Borrowed Souls（借魂）

GitHub **Game Off 2026** entry, theme **SHIFT**.

Hold **Shift** to tear your soul out of its body, then fight on in the enemies you defeat. Your soul can change bodies, but every body keeps its wounds.

*擊倒敵人、脫離肉身、侵入另一具容器，用奪來的職業與武器撐到最後。*

Unity 6 (6000.3.9f1), URP, WebGL. Play it on itch.io.

## Controls

| Action | Keys |
|---|---|
| Move | WASD |
| Aim | Mouse |
| Weak / Strong / Special attack | Left click / Right click / E |
| Dodge | Space |
| Leave your body (hold) | Shift |
| Lock on / change target | Tab / Mouse wheel |
| Pause | Esc |

## This repository

The code is here. Character models, music, sound effects and voices are not, so a clone opens without them and won't look like the game. Play the published build instead.
